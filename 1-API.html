Cisco ThousandEyes

2024 | Lead Product Designer | Web app | Enterprise |

Overview

I designed ThousandEyes’ first dedicated API testing experience, enabling users to continuously test API availability and performance from distributed network locations - beyond on-demand validation in tools like Postman.

The work established a phased foundation: launch with single-step API tests, then scale the configuration model and results views to support multi-step API workflows.

My Role

As the sole designer for the API testing experience, I:

    Defined the configuration flow and information architecture
    Designed single-step API test setup and a scalable path to multi-step tests
    Created API-specific inputs: method, endpoint, headers, authentication, body, and assertions
    Designed results views for API performance, availability, and failure investigation
    Presented concepts to customers and validated designs through customer testing
    Partnered with engineering to align the experience with the execution model
